# Retail Sales Dashboard

## 📊 Project Overview

This project showcases an interactive Retail Sales Dashboard created to analyze and visualize key business performance metrics.

The dashboard helps identify trends and insights related to sales, profit, products, customers, and regional performance.

## 🛠️ Tools & Technologies

- Power BI
- Snowflake
- SQL
- DAX
- Data Visualization

## 🚀 Dashboard Features

- 📊 **Interactive KPI Cards** – Displays key metrics such as Total Sales, Total Profit, Orders, and Unit Price.
- 📈 **Sales Performance Analysis** – Analyzes sales trends and overall business performance.
- 🗺️ **Regional Analysis** – Compares sales performance across different regions.
- 🛍️ **Category Analysis** – Identifies sales distribution across product categories.
- 🏷️ **Brand Analysis** – Visualizes discounts and performance across different brands.
- 👥 **Customer & Gender Analysis** – Analyzes sales and order distribution based on customer demographics.
- 📉 **Profit Analysis** – Provides insights into profit contribution and business growth.
- 🎛️ **Interactive Filters** – Allows users to filter and explore the dashboard based on different business dimensions.
- 📊 **Multiple Visualizations** – Uses bar charts, pie charts, line charts, and donut charts for better data interpretation.
  
## 📈 Key Analysis

- Sales performance analysis
- Profit analysis
- Regional performance
- Product and category analysis
- Customer insights
- Business trend analysis

## 🗄️ Data Source

The data used for this project was accessed through Snowflake. The original dataset is not included in this repository due to data availability and privacy considerations.
